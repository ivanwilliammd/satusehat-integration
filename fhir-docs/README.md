# FHIR Docs

Canonical documentation workspace for SATUSEHAT SDK generation.

Sources:
- FHIR R4 resource list: https://hl7.org/fhir/R4/resourcelist.html
- FHIR R4 StructureDefinitions / JSON schemas: https://hl7.org/fhir/R4/
- SATUSEHAT docs: https://satusehat.kemkes.go.id/platform/docs

Purpose:
- Track per-resource cardinality.
- Track SATUSEHAT terminology/value set options.
- Track supported `get/search/query by ...` methods.
- Feed future Node/Go/Python SDK generators.
